# CAN_Indicator_ESP32P4
Приборная панель для Pajero Sport 2.

Отображаемые параметры:
Скорость, текущая передача, обороты, крутящий момент, напряжение бортсети, температура двигателя, температура АКПП, уличная температура, салонная температура, Текущий пробег, два сбрасываемых счетчика пробега, одометр.

Контроллер ESP32-P4 https://aliexpress.ru/item/1005011541438684.html
Плата сопряжения дисплея https://aliexpress.ru/item/1005009918688380.html
